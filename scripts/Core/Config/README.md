# 遊戲平衡設定

常調整的機率、數量、門檻與倍率應放在所屬系統的 `Config`，玩法程式只負責執行規則。
新增系統時請建立新的 `{System}Config.cs`，不要把設定塞入不相關的 Config，也不要在角色或 UI
程式內直接寫掉落率魔法數字。

目前分工：

- `MonsterConfig.cs`：怪物稀有度、普通怪物素材與金幣規則
- `EquipmentConfig.cs`：裝備掉落、Boss 裝備數量、精煉與裝備評分
- `CardConfig.cs`：普通／Boss 卡片掉落、圖鑑加成與交換獎勵
- `CoreConfig.cs`：核心技能／輔助核心掉落、Boss 核心與欄位解鎖
- `BossConfig.cs`：Boss 素材數量與金幣倍率
- `WorldDropConfig.cs`：地面物品壽命、拾取距離、輪詢與回收上限

修改原則：

1. 機率統一使用 `0.0f` 到 `1.0f`，例如 `0.05f` 代表 5%。
2. 最小／最大值應成對命名，不要依賴呼叫端猜測範圍。
3. Config 不處理遊戲流程、不產生節點，也不直接操作玩家資料。
4. 同一個設定只保留一份來源；舊 API 如需相容，只能轉指向 Config。
